# The meridional structure of the land-ocean precipitation contrast
This repository contains code related to the collaborative project which originated from the EUCLIDYAN workshop at Castle Ringberg in 2026.

The folder `scripts` contains all analysis and plotting scripts relevant for the project's publication, and the folder `data` contains all small-sized data such as zonally averaged quantities and other processed data for the final figure generation.

If you want to contribute to this repository, please follow the standard git workflow of forking the repository (and cloning it to wherever you want to work on changes), and contributing changes through pull requests.
